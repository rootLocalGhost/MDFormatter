# Markdown Studio

A browser-based Markdown editor with a live preview, syntax-highlighted code blocks, LaTeX math, and Mermaid diagrams. The editor works as a static page and saves the current draft in the browser's local storage.

## Features

- Live GitHub-Flavored Markdown preview
- LaTeX math, Mermaid diagrams, and syntax-highlighted code
- Copyable and collapsible code blocks
- Word and character counts
- Exports to PDF, HTML, plain text, Word (`.docx`), and Markdown source

Open `index.html` in a modern browser to use the editor. Export libraries and rendering dependencies are loaded from public CDNs, so those features require an internet connection.
